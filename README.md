# GradeGoal
![Alt text](https://img.shields.io/badge/License-MIT-yellow.svg)
![Alt text](https://img.shields.io/badge/Version-V1.2.2-green.svg)

A web application that helps students set academic goals, track grades, and calculate what's needed to achieve target scores.

## 🚀 Built With
Backend: Java, Spring Boot

Frontend: HTML, CSS, JavaScript

Database: MySQL

IDE: IntelliJ IDEA

# ✨ Features
## 📊 Grade Tracking
- Add courses and assignments

- Calculate current grades in real-time

- Set target grades and see required scores

## 📈 Progress Monitoring
- Visual grade progression charts

- Semester GPA calculator

- Assignment weight management

- Auto calculate exam mark based on assessments and weights

- Get letter grade based on course mark

- Auto calculate average grade of courses and assessments

## 📱 User Experience
- Clean, intuitive interface

- Responsive design (works on desktop & mobile)

# ⚙️ Configuration
The application uses a securityConfig file for security-related settings (e.g., authentication, authorization). Ensure this file is properly configured before running the application.
